# 选择困难症终结者 / DecisionMate

《移动智能应用开发》课程项目，2026 年秋季 Aberdeen 第 4 组。

## 项目简介

一款帮助用户解决日常选择困难的 Android 智能决策应用，例如今天吃什么、周末去哪里、买哪双鞋、看哪部电影，以及和朋友玩什么。

## 计划功能

1. **AI 偏好学习**：用户对选择结果进行评价，应用逐渐建立偏好记录，提供个性化推荐。
2. **多人决策**：朋友在各自手机上提交意愿和投票，系统推荐大家都能接受的结果。
3. **反向选择**：用户提出不想选择的选项或条件，系统根据排除条件推荐结果。

已完成仓库初始化。上述功能为项目设想，尚未开始软件开发。
